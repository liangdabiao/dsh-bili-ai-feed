# B站爆款雷达

按关键词扫描 B 站作品（默认 AI），按点赞量筛选爆款视频，智能聚类后生成HTML日报。同步基于热门话题执行情报调查。

> **核心纪律**：数据每日15:00更新前一天数据。目标日期无数据时**禁止自动调用接口**——先告知用户并等待确认。

## 数据口径

- 数据查询接口：RedFox batch 接口（`X-API-KEY` 鉴权），`source` 字段同步记录，无需额外保存
- **日期规则**：每日15:00更新前一天数据；15:00 前最新可用 = T-2，之后 = T-1。工具内置此规则并拦截无数据日期
- **查询策略**：默认主关键词 `AI`，数据不足自动扩展（人工智能→大模型→GPT→Agent→AI绘画→AI教程），所有关键词 batch 接口一次批量查询；用户自定义关键词时仅用用户列表，同样批量
- **每条视频**：标题、UP主、封面图、点赞、评论、分享、发布时间；URL 用 photoId（BV号）拼接 `bilibili.com/video/{photoId}`
- **聚类**：基于 type+topic 标签六步算法（大组拆分/小组合并/标题关键词再拆/保底5类），分类由当天内容动态决定

## 工作流程

1. **日期预检**（第零步，工具自动执行）：目标日期落在无数据区间时工具返回 date_blocked——必须向用户输出确认话术并等待明确确认，确认后带 confirmNewer 重查；用户拒绝则不调接口
2. **生成日报**：`bili_feed(action="fetch", date?, keywords?)` → 分类概览 + 聚类结果 + 情报 briefing + HTML 日报落盘
3. **情报调查**：基于聚类 TOP3 话题自动执行（工具已内置确定性推导）；需要更深入时按调查模式（竞品/舆情/人物/验证）做多引擎搜索交叉验证，参照 [investigation-modes.md](references/investigation-modes.md) 与 [investigation-templates.md](references/investigation-templates.md)
4. **输出**：严格按下方模板输出

## 可信度标注规范

| 标识 | 含义 | 判定标准 |
|------|------|---------|
| ✅ 已确认 | 信息可靠 | 2+个独立来源一致 |
| ⚠️ 待确认 | 有争议 | 来源说法矛盾 |
| ❌ 已否定 | 信息不实 | 权威信源反驳 |
| 🔍 单一来源 | 仅1个来源 | 需进一步验证 |

信息源分级 A（官方/权威媒体）> B（行业媒体）> C（社交/自媒体）> D（匿名/未验证）。引擎选择详见 [engine-strategy.md](references/engine-strategy.md)。

## 调查纪律

- 所有数值来自数据服务返回，严禁估算编造；没查到写"暂无"，不删板块
- 日期拦截话术必须完整转述（日期/规则/最新可查日期/是否切换），用户确认前不产生任何接口调用
- 日报地址用工具返回的 HTML 路径，末尾带上数据源说明

## 面板

- 侧栏「B站爆款雷达」面板：直查日报（日期/关键词）、深色主题 HTML 日报（封面图+互动数据+视频直链）、历史归档。
- 深挖话题时引导用户「去对话调查」，agent 按调查模式做延伸搜索。
